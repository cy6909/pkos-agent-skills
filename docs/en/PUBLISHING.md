# Publishing

This repository is already structured for a GitHub-backed repo marketplace.

For the universal public Plugins Directory, use the OpenAI plugin submission portal. A skills-only plugin is supported.

Before submission:

- finalize the skill tree and plugin metadata;
- test the exact final files locally;
- prepare public website/support/privacy/terms URLs if required by the listing;
- prepare realistic starter prompts;
- provide at least five positive and three negative test cases;
- verify publisher identity and complete policy review.

Submission starts review; publication happens only after approval and an explicit publish action.
