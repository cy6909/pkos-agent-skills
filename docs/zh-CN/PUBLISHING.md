# 发布

本仓库已经符合 GitHub-backed Repo Marketplace 的目录方式，可以用于直接安装、开发测试和社区分发。

如果后续要进入 ChatGPT / Codex 共用的 Universal Public Plugins Directory，需要使用 OpenAI Plugin Submission Portal。Skills-only Plugin 可以提交。

提交前应完成：

- 固化最终 Skill Tree 和 Plugin Metadata；
- 使用最终文件树进行本地测试；
- 按公开 Listing 要求准备 Website / Support / Privacy / Terms；
- 准备真实 Starter Prompts；
- 至少 5 个 Positive Test + 3 个 Negative Test；
- 完成 Publisher Identity 与 Policy Review。

提交只代表进入审核；通过审核后还需要发布者主动 Publish，才会进入公共目录。
