# Security Policy

PKOS is a skills-only plugin. It does not include credentials or grant access to external systems.

## Report a vulnerability

Please open a private GitHub security advisory when available. Do not publish secrets, tokens, private Notion URLs, personal memory content, or reproducible sensitive data in a public issue.

## Data-handling principles

- External access is governed by the user's installed MCP/apps and source-system permissions.
- Skills must not ask users to paste credentials into project documentation.
- Sensitive memory requires explicit evidence and higher write thresholds.
- Delete/forget workflows must remove the fact from active/compiled memory views.
- Audit should retain only minimum governance metadata, not deleted sensitive content.
